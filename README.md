# Actividad-3-Flujo-Control
Este proyecto fue desarrollado en C++ para la asignatura Lógica de Programación. El programa solicita la cantidad de estudiantes, registra sus nombres y cuatro calificaciones, calcula el promedio y determina si aprobaron o reprobaron. Para su desarrollo se utilizaron bucles, estructuras de decisión (if-else) y una salida de datos organizada.

Objetivo.

Desarrollar un programa utilizando bucles que permita registrar las calificaciones de varios estudiantes, calcular el promedio de cada uno y mostrar si aprobó o reprobó.

Funciones del programa.

- Solicita la cantidad de estudiantes.
- Pide el nombre del estudiante.
- Solicita cuatro calificaciones.
- Calcula el promedio.
- Determina si el estudiante aprobó o reprobó.
- Muestra la información organizada en una tabla.
  
  Tecnologías utilizadas.
  
- Lenguaje: C++
- Compilador: Online C++ Compiler
